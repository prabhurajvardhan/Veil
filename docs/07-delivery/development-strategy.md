# Development Strategy

## Engineering Delivery Lifecycle (CONFIRMED terminology from brief — do not call this "DevOps" or "Agile")

Phase 1 — Requirements Freeze
Phase 2 — Architecture Freeze
Phase 3 — System Design Freeze
Phase 4 — Module Freeze
Phase 5 — Sprint Planning
Phase 6 — AI Employee Allocation
Phase 7 — Implementation
Phase 8 — Validation and Integration
Phase 9 — Release

Architecture and System Design each follow: V0 → validation → V1 → validation → V2 → validation → V3 → validation → FREEZE. Do not jump to implementation while architectural uncertainty remains.

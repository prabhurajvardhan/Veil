# Definition of Done

## Module — Done When (PROPOSED)
- Interface contract implemented matches `05-engineering/interface-contracts.md`.
- Unit tests pass (see `10-quality/test-strategy.md`).
- No known privacy-boundary violation introduced.

## Integration — Done When (PROPOSED)
- All modules in the pipeline connect according to `06-modules/dependency-map.md` without violating `05-engineering/dependency-rules.md`.
- Integration tests pass (`10-quality/integration-strategy.md`).

## Milestone — Done When (PROPOSED)
- All associated tasks in `09-team/task-registry.md` reach status DONE (`09-team/status-protocol.md`).

## V1 — Done When (CONFIRMED, from success-criteria.md)
- The full closed loop completes for at least one real task, and all ten acceptance-test scenarios pass.

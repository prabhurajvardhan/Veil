## 4. Task Execution Workflow (How to work)
1. Open [`TASKS.md`](../../TASKS.md) and filter the table by **OWNER = AI001**.
2. Identify tasks with **STATE = READY**. (Do NOT start `BLOCKED` or `PLANNED` tasks).
3. Open the specific task document (e.g., `docs/tasks/T001.md`).
4. Read ALL documents linked in the **Mandatory References** section of that task document.
5. Implement the code strictly within your **Allowed Scope**.
6. Validate against the task's **Acceptance Criteria**.
7. Update the task state to `VALIDATED` in both the task file and `TASKS.md`.
8. Execute integration handoff procedures (Open PR / Ping Integration).

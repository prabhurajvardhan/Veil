4. Read ALL documents linked in the **Mandatory References** section of that task document.
5. Implement the code strictly within your **Allowed Scope**.
6. Validate against the task's **Acceptance Criteria**.
7. Update the task state to `VALIDATED` in both the task file and `TASKS.md`.

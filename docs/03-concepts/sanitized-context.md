# Concept: Sanitized Context

## Definition
The only data structure permitted to cross the network boundary toward the cloud reasoning model — structured, and verified free of detected sensitive content.

See `02-system-design/reasoning/context-contract.md` for schema status (currently UNKNOWN/draft).

## Why It Exists
Directly implements Privacy Principle #3 ("Cloud reasoning does not receive unrestricted screen access") and ADR-007/ADR-008.

# Concept: Cloud Reasoning

## Definition
The external reasoning model that receives sanitized context and proposes the next action toward completing the user's task.

See `02-system-design/reasoning/cloud-reasoning.md` for design detail.

## Why It Exists
Provides the planning/reasoning capability that local, on-device models are assumed (ASSUMPTION, not yet validated) insufficient to provide for arbitrary tasks — while deliberately holding no execution authority (Privacy Principle #4).

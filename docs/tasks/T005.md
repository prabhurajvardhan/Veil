### Architecture Specification: Prototype vs. Future
- **CURRENT PROTOTYPE BACKEND:**
  - Hugging Face hosted visual inference (`HuggingFaceProvider`).
  - Uses hosted endpoint (`router.huggingface.co/hf-inference/models/showlab/ShowUI-2B` or configured Hugging Face Space/Inference Endpoint).
  - Clean `VisualInferenceProvider` abstraction implemented and used by `ShowUIAdapter`.
  - **PRIVACY BOUNDARY NOTICE:** The prototype hosted inference path transmits screenshot data outside the device to the Hugging Face hosted inference backend. This does NOT provide the final on-device privacy guarantee and is strictly an interim unblocker for prototype integration.
- **FINAL / POST-HACKATHON BACKEND:**
  - `ShowUI-2B → ONNX → ONNX Runtime Web → WebGPU` (`LocalONNXProvider`).
  - On-device local execution ensuring complete zero-data-leakage visual perception.
  - Frozen architecture preserved (ADR 005).

### Audited Components (VALID & OPERATIONAL)
- `VisualInferenceProvider` clean abstraction decoupling perception logic from execution backend.
- `HuggingFaceProvider` real HTTP inference client with full fail-closed error handling (network, auth 401/403, 503 unavailable, timeout, malformed response).
- `LocalONNXProvider` representing the frozen future architecture (fails closed until local ONNX weights/runtime are provisioned).
- `ShowUIAdapter` orchestrator integrating `VisualInferenceProvider` with fail-closed screenshot validation, confidence threshold filtering, and `VisualEvidence` generation.
- BoundingBox & VisualEvidence data contracts conforming strictly to `INTERFACES.md`.
- Coordinate normalization, scaling (1000-scale and unit-scale), clamping, and parsing in `CoordinateParser`.
- Full support for ShowUI-2B native output formats:
  - Grounding point coordinates: `[x, y]` (unit scale or 1000 scale)
  - Python action dictionaries: `{'action': 'CLICK', 'position': [0.73, 0.21]}`
  - Two-point selection boxes: `{'action': 'SELECT_TEXT', 'position': [[0.1, 0.2], [0.8, 0.9]]}`
  - Four-coordinate bounding boxes: `[ymin, xmin, ymax, xmax]` and `<box>...</box>` tags
- Fail-closed screenshot input validation (`InvalidScreenshotError`).
- Fail-closed error hierarchy (`VisualPerceptionError`, `InvalidScreenshotError`, `BackendAllocationError`, `ModelInferenceError`, `CoordinateParsingError`).
- Offscreen document request/response message handling protocol (`OffscreenVisualGroundingRequest` / `OffscreenVisualGroundingResponse`).

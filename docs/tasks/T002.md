## 5. Implementation Specifications
- **PURPOSE:** Extract raw pixels and DOM tree from the active tab.
- **REQUIRED INPUTS:** Trigger from M01.
- **EXPECTED OUTPUTS:** `RawObservation` object.
- **IMPLEMENTATION BEHAVIOR:** Use `chrome.tabs.captureVisibleTab` and DOM injection to retrieve state.
- **ERROR/FAILURE BEHAVIOR:** If tab is inaccessible, return explicit failure, not silent empty state.

## 6. Validation & Handoff
- **ACCEPTANCE CRITERIA:** Returns a valid Base64 image string and a structured DOM snapshot.
- **VALIDATION METHOD:** Invoke M02 trigger manually via extension console.
- **TEST REQUIREMENTS:** Unit test for capture failure scenarios.
- **VISIBLE RESULT:** Payload dumped to console.
- **HANDOFF REQUIREMENTS:** Change state to `VALIDATED`, update `TASKS.md`.
